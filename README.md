# Loading Zone Comedy / 候场喜剧 — V4 · V2 UI

本版本采用 V2 的 UI/视觉方向，同时保留 V4 的内容结构。

## 演出内容规则
- 用户提供的 10 张照片全部属于 **Past Shows / 过往演出 Gallery**，不作为近期演出默认图片。
- **Upcoming Shows / 近期演出**支持两种来源：
  1. **Eventbrite 自动导入**：标题、日期、时间、场地、图片、票务链接、活动状态等。
  2. **手动添加**：用于其他场地或其他售票平台开票的演出。
- Eventbrite 同步不会覆盖网站手动维护的中文标题、中文简介、置顶、首页展示、排序等字段。
- Past Shows Gallery 独立管理，可从后台继续上传照片、添加演出关联和说明。
- 会员免费开放麦活动目前只从 Eventbrite 导入；目前仅 Melbourne 有此类免费活动。Sydney 或 Brisbane 将来有免费活动时，也必须从 Eventbrite 导入，不可在没有真实活动来源时手动伪造活动。
- 商业/专业演出可来自 Eventbrite 或其他第三方售票平台；后台需允许手动维护这类演出及其折扣适用规则。

## 会员规则与票务折扣工作流
- 三个城市：Melbourne、Sydney、Brisbane；一个会员账户、一份会员资格，会员可切换偏好城市查看当地商户福利和符合条件的免费活动。
- 会员价格统一：A$12.80/月或 A$99.80/年。
- 符合条件的商业/专业演出在三个城市统一优惠 **A$10 off**，但具体演出可设置是否适用及相关条款。
- 每位会员分配一个独立的专属折扣码，不同会员不可共用。专属码可用于符合规则的线下免费活动入场或商演门票折扣。
- 网站后台应支持管理员安全地导出会员资料及专属码，以便在对应的售票平台创建/配置折扣码。
- 票务平台不局限于 Eventbrite：商演可通过 Eventbrite 或其他第三方平台售票。网站生成/分配专属码不等于第三方平台已创建或启用该码；管理员需在相应平台配置优惠金额、适用活动、使用限制等。
- 后续应记录码的分配与状态，并在导出时仅包含票台设置所必需的字段，避免导出不必要的敏感会员信息。折扣码必须唯一，会员状态失效后应能停用或标记为不可用；第三方票台的实际核销能力取决于平台支持。
- 会员福利文案需区分“符合规则的线下免费活动入场”和“商演门票 A$10 优惠”，不可让用户误以为所有线下演出均免费。每场活动的适用条件以该场演出规则为准。

## 其他已确认内容
- 正式 Logo 使用用户提供的 `269.png`，不从演出照片裁切。
- 首页 Hero 使用用户最新提供的舞台照片。
- Past Shows 使用横向滑动 Gallery。
- 会员默认一次性购买，可选择自动续费。
- 电子会员卡不使用 QR Code。
- 中文优先，并提供 English 切换。

## 生产环境仍需接入
- Eventbrite OAuth/API 后端
- Stripe Checkout / Billing 与 webhook
- 会员数据库、OTP 登录
- 管理后台鉴权与权限
- 专属折扣码的生成、唯一性校验、会员状态联动、受权限保护的 CSV 导出
- 各票务平台折扣码创建/核销流程（如平台没有 API，则由管理员手动配置）
- Hosting / DNS / HTTPS
