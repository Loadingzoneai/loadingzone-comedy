# 网站功能推进记录

本次在 `feature/membership-integration` 基础上建立 `codex/website-completion` 本地分支。未修改正式网站、Stripe 正式收款或数据库结构。

## 本次完成的代码

- 近期演出：从指定 Eventbrite organization 读取公开、未结束的活动，支持分页及五分钟缓存；密钥仅在服务器使用。该实现替代仓库中原有的演出占位卡片。
- 手动演出：后台填写名称、墨尔本时间、场地、购票链接、简介、海报；支持草稿、发布、置顶。海报可跳转到购票平台。
- 过往演出：独立后台录入和海报上传，保留既有 10 张历史照片作为未配置时的展示。
- 内容安全：公开接口只返回已发布演出；所有编辑和会员列表读取均检查管理员身份；链接只允许 HTTPS，文本在页面转义。
- 会员：邮箱验证码注册／登录、本人会员状态与到期时间查询、测试付款、Stripe 测试订阅管理入口。手机号验证码和一次性付费尚未实现。
- 收款可靠性：防止已有订阅再次购买；签名验证读取原始通知内容；失败通知可重试；已处理通知不重复更新；根据 Stripe 最新订阅状态及新版项目级账期字段同步会员。
- 手机界面：保留全部主要导航；修复 Logo 路径，优化会员表单、海报和焦点样式。

## 发布预览前的配置核对

沿用现有 Vercel + Supabase + Stripe，不需要更换平台。以下只列变量名称，不包含密钥：

| 配置 | 用途 |
| --- | --- |
| `SUPABASE_URL` | 数据库与邮箱认证项目 |
| `SUPABASE_PUBLISHABLE_KEY` | 浏览器邮箱认证 |
| `SUPABASE_SECRET_KEY` | 服务器读写会员及网站内容 |
| `ADMIN_EMAILS` | 逗号分隔的管理员邮箱名单 |
| `EVENTBRITE_PRIVATE_TOKEN`（兼容 `EVENTBRITE_TOKEN`） | 候场喜剧 Eventbrite API 访问 |
| `EVENTBRITE_ORGANIZATION_ID`（兼容 `EVENTBRITE_ORG_ID`） | 必须核对为候场喜剧组织，避免导入其他组织活动 |
| `STRIPE_SECRET_KEY` | 本版仅接受 `sk_test_` 测试密钥 |
| `STRIPE_TEST_PRICE_MONTHLY` / `STRIPE_TEST_PRICE_ANNUAL` | 测试环境月付、年付价格 |
| `STRIPE_WEBHOOK_SECRET` | 测试环境付款通知签名 |

1. 通过正常 GitHub 授权提交预览分支，让 Vercel 生成新的预览部署；不要直接覆盖正式部署。
2. 核对现有 Supabase `members`、`stripe_events` 表及字段与 API 一致，并核对用户身份对应关系、唯一性约束和访问策略。本次未创建基础会员表。
3. 检查 `site_content` 表及 `site-media` 存储桶是否已存在；如不存在，需先审查仓库中已有 CMS migration，再在正确环境应用。本次未应用任何 migration。
4. 管理员账号需已在 Supabase Auth 创建。管理员登录不自动创建账号；服务端使用 `ADMIN_EMAILS` 决定权限。
5. 核对邮箱验证码模板和邮件投递；核对 Stripe 测试 Billing Portal 设置和 webhook 端点。
6. 用测试用户验证注册、月付、年付、取消付款、失败付款、到期、取消续费和刷新会员状态。确认网页返回成功不能直接开通会员。
7. 核对中文／英文全部文案。目前新增会员和演出页面支持语言切换，沿用的首页／后台仍有中文文案。
